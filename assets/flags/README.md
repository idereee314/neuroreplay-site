# Flags

4:3 SVG flags from [flag-icons](https://github.com/lipis/flag-icons) v7.6.0 (MIT licence,
© 2013 Panayiotis Lipiridis), stored locally so the site needs no CDN and keeps working offline.

Each language in `i18n.js` (`LANGUAGES[].flag`) points at one of these files.
To add a language, copy its flag from `flag-icons/flags/4x3/<country>.svg` into this folder.
