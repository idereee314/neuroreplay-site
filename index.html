FAQ

Түгээмэл асуултуудFrequently asked questions

Ямар камер тохирох вэ?Which cameras are compatible?

Windows-д таних USB камер, мөн RTSP/IP урсгал дэмждэг сүлжээний камерууд (FFmpeg-ээр). USB болон IP камерыг зэрэг холбож болно.Any USB camera Windows recognises, plus network cameras that provide an RTSP/IP stream (via FFmpeg). You can mix USB and IP cameras at once.

Заавал Windows дээр ажиллах уу?Does it require Windows?

Тийм. NeuroReplay бол Windows 10/11 дээр ажилладаг desktop программ хангамж. macOS, Linux хувилбар одоогоор байхгүй.Yes. NeuroReplay is Windows 10/11 desktop software. There is no macOS or Linux build at this time.

Лиценз хэрхэн идэвхждэг вэ?How does license activation work?

Хоёр хувилбар бий: тэмцээнд зориулсан .lic файл (ямар ч компьютер дээр, заасан өдрүүдэд ажиллана) эсвэл нэг компьютерт уягдсан license key. Захиалгын дараа бид файл/түлхүүр, зааврыг өгнө.There are two options: an event .lic file (works on any computer for the set dates) or a licence key bound to one computer. After ordering we send the file or key with instructions.

Competition ба Analyze ямар ялгаатай вэ?What's the difference between Competition and Analyze?

Competition бол үндсэн эрх: live, instant replay, бичлэг, TAG, клип экспорт. Analyze нь дээр нь нэмэгдэх лиценз: зураглал, өнцөг хэмжилт, A|B харьцуулалт, техникийн оноо, байрлалын хугацаа, статистик, highlight reel, AI шүүгчийн дохио.Competition is the base licence: live, instant replay, recording, tagging and clip export. Analyze is an add-on licence: drawing, angle measurement, A|B compare, technique points, position time, stats, highlight reels and AI referee signals.

AI шүүгчийн дохиог аль спортод таних вэ?Which sports does the AI referee-signal detection support?

Жүдо (иппон, ваза-ари, осаэкоми, матэ), UWW бөх (1/2/4/5 оноо), БЖЖ (2/3/4 оноо, давуу тал), самбо (1/2/4 оноо, тодорхой ялалт). Энэ нь Beta туслах хэрэгсэл — зөвхөн санал болгох ба TAG болгохыг оператор баталгаажуулна. Нарийвчлал нь шүүгч кадрт хэр том, тод харагдахаас хамаарна.Judo (ippon, waza-ari, osaekomi, matte), UWW wrestling (1/2/4/5 points), BJJ (2/3/4 points, advantage) and sambo (1/2/4 points, total victory). It is a beta assistant — it only suggests, and the operator confirms each tag. Accuracy depends on how large and clear the referee is in frame.

Интернэтгүй ажиллах уу?Can it run offline?

Тийм. Бичлэг, replay, анализ, экспорт бүгд интернэтгүй, дотоод сүлжээгээр ажиллана.Yes. Recording, replay, analysis and export all work offline over your local network.

Хадгалалт, дискний зай хэр их вэ?How much storage do I need?

Зай нь камерын тоо, нягтрал, бичлэгийн урт, DVR буферээс хамаарна. Тэмцээний өдрийн бичлэгт хурдан SSD зөвлөж байна; тодорхой тооцоог бид тантай хамт гаргана.It depends on the number of cameras, resolution, recording length and DVR buffer. We recommend a fast SSD for match-day capture and will help you size it.

RTSP камерыг хэрхэн тохируулах вэ?How do I set up an RTSP camera?

IP камераа LAN-д холбож, RTSP хаяг (rtsp://…), нэвтрэх мэдээллийг программ хангамжид оруулна. FFmpeg урсгалыг задалж бусад камертай синклэнэ. Суурилуулалтад бид тусална.Connect the IP camera to your LAN and enter its RTSP URL (rtsp://…) and credentials in the software. FFmpeg decodes the stream and syncs it with your other cameras. We help with setup.
